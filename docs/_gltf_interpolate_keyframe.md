# _gltf_interpolate_keyframe   
   
[返回上级](./__init__.md)   
   
**签名**: `_gltf_interpolate_keyframe(times, values, interpolation, target_time, path)`   
   
在指定时间插值关键帧   
:param times:        时间戳列表   
:param values:       值列表   
:param interpolation: 插值类型   
:param target_time:  目标时间   
:param path:         通道路径（"rotation"表示四元数旋转）   
:return: 插值结果
